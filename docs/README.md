# Documentación del Proyecto cobroWeb

## Descripción General
Sistema de cobro en línea para el Gobierno del Estado de Morelos. Proporciona funcionalidades para:
- Pago de refrendo vehicular
- Gestión de trámites relacionados con Hacienda
- Procesamiento de pagos diversos

## Tecnologías Principales
- Angular (v15+)
- TypeScript
- Material Angular
- Node.js
- Docker

## Estructura Básica
```
cobroWeb/
├── src/                  # Código fuente principal
│   ├── app/              # Módulos y componentes Angular
│   ├── assets/           # Recursos estáticos
│   └── environments/     # Configuraciones de entorno
├── data/                 # Datos y configuraciones JSON
└── docs/                 # Documentación del proyecto
```

## Requisitos
- Node.js v16+
- Angular CLI
- Docker (para despliegue)

## Configuración Inicial
```bash
npm install
ng serve
```
